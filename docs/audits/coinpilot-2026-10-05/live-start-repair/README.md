검토일: 2026-10-05, 한국 시간.

이 문서는 1차 점검 기록이다. 이어서 반영한 서버 수정, **TestFlight 1.0 (21) 배포**, 90일 자료 진단과 최신 검증 범위는 [후속 점검 기록](continuation.md)을 따른다.

시작 실패의 원인 안내와 검증 자료 갱신 경로는 수정하여 운영 서버에 반영했다. **현재 전략은 새 검증에서도 통과하지 못했으므로 실거래 자동매매 시작은 계속 제한된다.** 실제 시작 성공이나 거래소 주문을 검증한 기록으로 해석하지 않는다.

## 확인한 원인

- 운영 LIVE 서버는 정지 상태였으며 계좌 상태 확인, 키 등록, 수동 준비가 완료되어 있었다. 관리 포지션은 0개였다.
- 설정된 `scalping_validation.json`이 없었다. 운영 소스에는 로컬에 있는 검증 갱신기도 없었다.
- 시작 경로는 `실전 매매 차단` 문구만 보존하여 실제 기본 스캘핑의 `실전 스캘핑 차단` 오류를 일반적인 시작 실패로 바꿨다.
- 네이티브 앱은 시작 응답을 표시한 직후 대시보드를 새로고침하면서 그 안내를 지웠다.

## 수정과 반영

서버는 알려진 시작 차단 이유를 안정적인 코드와 한국어 안내로 응답한다. 원본 오류, 파일 경로, 내부 보고서 내용은 반환하지 않는다. 기존 시작 검증, 중지, 수동 보호 감시는 유지했다.

운영 서버에는 현재 서버 소스를 별도로 읽고 해시를 확인한 뒤 다섯 파일에 한정한 패치를 반영했다. 오류 분류와 시작 응답, 수동 준비 이후의 검증 갱신기 연결, 검증 보고서의 임시 파일 작성 후 rename만 포함한다. 자동 복구나 새로운 매매 시작 호출은 배포하지 않았다. 이전 파일은 `/root/coinpilot-backups/20261005-start-repair-01a10bc0`에 보존했다. [deployment-manifest.json](deployment-manifest.json)과 [deployed.patch](deployed.patch)에 정확한 범위가 있다.

검증 갱신기는 차단된 시작 요청에서 갱신을 예약한다. 갱신 결과가 실패하면 시작 조건은 계속 닫혀 있으며, 보고서 생성으로 자동매매를 시작하지 않는다. 정지한 운영자는 명시적으로 시작을 다시 요청해야 한다.

네이티브 소스는 최근 시작·중지 응답을 새로고침 후에도 유지하고 조회 오류를 함께 표시한다. 로그아웃, 서버·작업공간 변경, 실제 거래 모드 불일치는 이전 안내를 지운다. 실행 상태는 서버 응답만 사용한다. 이 네이티브 수정은 Simulator 빌드까지 검증했으며 이 작업에서 TestFlight 업로드나 실기기 설치는 하지 않았다.
