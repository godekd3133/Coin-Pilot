현재 서버
서버 주소를 모르겠어요

CoinPilot을 실행한 관리자에게 서버 주소를 요청해 주세요. 같은 Wi-Fi의 Mac 서버는 내부 주소로, 외부 서버는 HTTPS 주소로 연결합니다. 이 화면에는 거래소 API 키를 입력하지 않습니다.

연결만으로 새 주문을 보내거나 자동매매를 시작하지 않습니다.
